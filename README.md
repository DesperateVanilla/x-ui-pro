# 🚀 3X-UI Pro (3X-UI + Nginx)

Форк проекта [mozaroc/x-ui-pro](https://github.com/mozaroc/x-ui-pro) (основан на [GFW4Fun/x-ui-pro](https://github.com/GFW4Fun/x-ui-pro) и работах legiz-ru).

Оптимизированный скрипт автоматической установки панели **3X-UI** с поддержкой **VLESS-Reality**, **VLESS-WS**, **VLESS-XHTTP**, **Trojan-gRPC**, **Hysteria 2** и **AmneziaWG**. Веб-транспорты работают через **Nginx**.

---

## 🔥 Особенности данной сборки

- 📦 **Всегда последняя версия панели**: Автоматическое скачивание актуального релиза панели [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui).
- ⏳ **Ожидание DNS**: Установка и смена доменов ждут привязки обоих имён к IP сервера перед запросом сертификатов.
- 👤 **Единый клиент (Single Client)**: При первой установке автоматически создается один клиент (`first`) сразу под все протоколы (**VLESS REALITY**, **VLESS WS**, **VLESS XHTTP**, **Trojan gRPC**, **Hysteria 2**, **AmneziaWG**).
- ⚡ **Поддержка Hysteria 2**: Автоматическая настройка протокола Hysteria 2 (UDP/QUIC, TLS ALPN `h3`) с автоматическим открытием портов в UFW.
- 🤖 **Интеграция Cloudflare WARP**: Встроенный обход блокировок для ИИ-сервисов (OpenAI, ChatGPT, Claude) через локальный SOCKS5-прокси WARP.
- 🚀 **Поддержка XHTTP**: Автоматическая настройка нового протокола XHTTP для обхода блокировок.
- 🔒 **Nginx SSL & Snippet Routing**: Маскировка трафика, авто-продление SSL через Certbot, daily reload Nginx.
- 🌐 **Персональная страница подписки (Web Sub Page)**: Готовая красиво оформленная страница подписки под Sing-Box, Clash Meta и стандартные клиенты.
- 🛡️ **Автонастройка Firewall (UFW)**.
- 🎲 **Случайные фейковые сайты (150+ шаблонов)** для маскировки REALITY.

---

## 📂 Описание скриптов

В этом репозитории есть несколько полезных скриптов для разных задач:

- **`x-ui-pro.sh`** — Главный скрипт автоматической установки. Ставит панель с нуля и настраивает связку с Nginx и сертификатами.
- **`change_domain.sh`** — Скрипт для быстрой смены основного домена и домена REALITY на работающем сервере без переустановки.
- **`switch_to_ip.sh`** — Скрипт для полного отказа от доменов и перевода сервера на работу по чистому IP-адресу.
- **`add_warp.sh`** — Скрипт для интеграции Cloudflare WARP и настройки маршрутизации на уже работающий сервер.
- **`x-ui-latest.sh`** — Аналог главного скрипта, используется для тестирования свежих фич (например, последняя версия панели с XHTTP).
- **`add_protocol.sh`** — Скрипт для безопасного добавления новых протоколов в *уже установленную* панель без перезаписи ваших клиентов и настроек.
- **`backup.sh`** — Утилита для создания резервной копии базы данных `x-ui.db` и важных конфигураций.

## 📋 Требования

> ⚠️ **Вам понадобятся 2 домена (или поддомена):**
> 1. **Основной домен (Panel & Inbounds)** — для панели, подписок, VLESS-WS, Trojan-gRPC и Hysteria 2. (A-запись указывать на IP сервера).
> 2. **Reality домен (Target)** — назначение для маскировки VLESS-Reality.

Совместимые ОС: **Ubuntu 20.04 / 22.04 / 24.04**, **Debian 11 / 12**.

Нативные установщики проверены с **3x-ui v3.11.0 / Xray-core v26.10.21**. При запуске загружается последний стабильный релиз панели, а управляющий скрипт берётся из того же тега. Поддерживаемые архитектуры: x86_64, ARM64, ARMv6/ARMv7 и x86; для ARMv7 используется совместимый ARMv6-бинарник конвертера подписок.

## 💻 Установка

Запустите команду на чистом сервере под пользователем `root`:

```bash
bash <(wget -qO- https://raw.githubusercontent.com/DesperateVanilla/x-ui-pro/master/x-ui-pro.sh) -install yes -panel 1 -ONLY_CF_IP_ALLOW no
```

### Параметры запуска:
| Флаг | Значение по умолчанию | Описание |
| --- | --- | --- |
| `-install` | `yes` | Автоматическая установка необходимых пакетов |
| `-panel` | `1` | Тип панели (3X-UI) |
| `-ONLY_CF_IP_ALLOW` | `no` | Ограничивать ли доступ к подпискам только IP Cloudflare |
| `-subdomain` | *(запрашивается)* | Ваш основной домен для панели и SSL |
| `-reality_domain` | *(запрашивается)* | Домен для REALITY |
| `-warp` | `no` | Автоматическая установка Cloudflare WARP и настройка обхода блокировок для ИИ-сервисов (OpenAI, Claude и др.) |

После ввода двух разных доменов скрипт проверяет их **каждые 15 секунд без ограничения времени**. Можно создать или исправить DNS-записи прямо во время ожидания; установка продолжится автоматически. **Ctrl+C** отменяет ожидание. Имена с кириллицей указывайте в punycode.

Проверяются системный DNS и публичные резолверы **1.1.1.1 / 8.8.8.8**; серверу нужен доступ к ним по DNS. Все A-записи должны указывать на публичный IPv4 сервера. Если есть AAAA-записи, они должны указывать на его публичный IPv6; лишние или устаревшие адреса нужно удалить. При использовании Cloudflare включите **DNS Only** (серое облако). Старая запись в одном из DNS-кешей означает, что ожидание продолжится. Это также работает с `-auto_domain yes` и `x-ui-latest.sh`.

До завершения проверки скрипт не останавливает панель, не очищает её файлы и не отправляет запросы Certbot. Проверка DNS не заменяет доступность порта **80/TCP** для Let's Encrypt.

## 🤖 Интеграция Cloudflare WARP (на уже работающий сервер)

Если у вас уже установлен `x-ui` (без переустановки с нуля) и вы хотите добавить обход блокировок для ИИ-сервисов (OpenAI, ChatGPT, Claude) через SOCKS5-прокси WARP, запустите отдельный скрипт:

```bash
sudo su -c "bash <(wget -qO- https://raw.githubusercontent.com/DesperateVanilla/x-ui-pro/master/add_warp.sh)"
```

Скрипт автоматически установит `warp-cli`, переведет его в режим локального прокси и аккуратно обновит вашу конфигурацию X-UI (xrayTemplateConfig) для перенаправления доменов в WARP.

## ➕ Добавление протоколов (без переустановки)

Чтобы восстановить удалённые подключения или добавить недостающие протоколы без переустановки, выполните:

```bash
sudo su -c "bash <(wget -qO- https://raw.githubusercontent.com/DesperateVanilla/x-ui-pro/master/add_protocol.sh) all"
```

Проверяется полный набор: **VLESS REALITY, VLESS WS, VLESS XHTTP, Trojan gRPC, Hysteria 2 и AmneziaWG**. Существующие локальные подключения, в том числе выключенные, пропускаются. Создаются только недостающие; к ним привязываются сохранённые клиенты. Подключения удалённых узлов не считаются существующими локальными протоколами.

Повторный запуск не создаёт дубликаты и не меняет настройки имеющихся подключений. Перед добавлением сохраняется резервная копия базы; изменения выполняются через API работающей панели. Идентификаторы подключений не перенумеровываются.

Для одного протокола вместо `all` укажите `reality`, `ws`, `xhttp`, `trojan`, `hy2` или `awg`. Без аргумента используется `all`. Команду запускайте на сервере, подключения которого нужно восстановить.

Оба основных установщика при обнаружении существующей базы переходят в этот режим восстановления. При новой установке также создаётся весь набор из шести протоколов.

## 🔄 Смена домена (без переустановки)

Если ваш текущий домен заблокирован или вам необходимо перенести сервер на новые домены без переустановки системы и потери базы данных клиентов, используйте скрипт смены домена:

```bash
sudo su -c "bash <(wget -qO- https://raw.githubusercontent.com/DesperateVanilla/x-ui-pro/master/change_domain.sh)"
```

Также можно сразу передать новые домены параметрами (без интерактивных вопросов):
```bash
sudo su -c "bash <(wget -qO- https://raw.githubusercontent.com/DesperateVanilla/x-ui-pro/master/change_domain.sh) -subdomain new.domain.tld -reality_domain newreality.domain.tld"
```

### Что делает скрипт:
1. Выпускает новые SSL-сертификаты через Let's Encrypt (Certbot) для основного домена и домена REALITY.
2. Обновляет конфигурации Nginx (`stream.conf`, `80.conf`, виртуальные хосты) с защитой от коллизий поддоменов.
3. Обновляет домены во всех активных подключениях в базе данных `3x-ui` (VLESS-WS, Trojan-gRPC, Hysteria 2, Reality).
4. Сохраняет HTTP-доступ к панели за Nginx, который обслуживает HTTPS с новыми сертификатами.
5. Проверяет корректность синтаксиса Nginx (`nginx -t`) и перезапускает службы `nginx` и `x-ui`.

Скрипт дождётся обновления A/AAAA-записей обоих новых доменов перед выпуском сертификатов и изменением конфигураций. При Cloudflare используйте режим **DNS Only** (серое облако).

## 🌐 Отказ от доменов и переход на IP (без переустановки)

Если вы хотите полностью отказаться от доменов (например, из-за блокировок ТСПУ по SNI бесплатных зон или лимитов Let's Encrypt) и перевести сервер на работу исключительно по **IP-адресу сервера**:

```bash
sudo su -c "bash <(wget -qO- https://raw.githubusercontent.com/DesperateVanilla/x-ui-pro/master/switch_to_ip.sh)"
```

Также можно передать параметры напрямую:
```bash
sudo su -c "bash <(wget -qO- https://raw.githubusercontent.com/DesperateVanilla/x-ui-pro/master/switch_to_ip.sh) -reality_sni gateway.icloud.com"
```

### Что делает скрипт:
1. Выпускает самоподписанный SSL-сертификат с Subject Alternative Name для IP-адреса сервера (`IP:x.x.x.x`).
2. Настраивает мультиплексирование Nginx Stream на порту 443:
   - Запросы напрямую по IP (без SNI) прозрачно маршрутизируются в веб-сервер панели и подписок.
   - Запросы VLESS-Reality с маскировочным SNI (по умолчанию `gateway.icloud.com`) маршрутизируются в Xray.
3. Открывает доступ к подпискам и веб-странице клиента как по **HTTPS**, так и по прямому **HTTP** (порт 80), исключая ошибки проверки SSL в сторонних клиентах.
4. Переключает VLESS-Reality на реальный внешний целевой сервер (`gateway.icloud.com:443`), исключая блокировки ТСПУ и необходимость выпуска сертификатов под Reality.
5. Обновляет все инбаунды и настройки в SQLite базе данных `3x-ui` и перезапускает сервисы.

## 🛠️ Возможные проблемы и нюансы (Troubleshooting)

### Ошибка: `dpkg was interrupted` или пакеты не устанавливаются
Если в процессе установки вы получаете ошибки вида `E: dpkg was interrupted...`, `nginx.service does not exist` или `certbot: command not found`, это означает, что пакетный менеджер Ubuntu был прерван во время предыдущих обновлений или установок.

**Решение:**
Вручную восстановите состояние пакетов на сервере командой:
```bash
dpkg --configure -a
```
При необходимости (если есть поврежденные зависимости):
```bash
apt-get install -f
```
После успешного выполнения этих команд запустите скрипт установки повторно.

### Ошибка: `SSL could not be generated!`
Обычно возникает, если вы указали домен, который еще не привязан к IP-адресу вашего сервера, или вы используете проксирование Cloudflare (оранжевое облако) на момент получения сертификата (Let's Encrypt не может достучаться до сервера напрямую).

**Решение:** 
Убедитесь, что A-запись домена (или поддомена) ведет строго на IP-адрес вашего сервера. Если используете Cloudflare — отключите проксирование (сделайте облако серым / DNS Only) на время первой установки скрипта и генерации сертификата. После завершения установки можно включить проксирование обратно.

## AI & Global Bypass Routing (WARP+)
The installer now features a fully automated integration with Cloudflare WARP+ and `roscomvpn` geo-databases to bypass advanced DPI and AI service geo-blocks (such as Google Gemini, Antigravity, ChatGPT, Claude).

**Features:**
- Installs official `cloudflare-warp` and proxies traffic via local SOCKS5.
- Automatically scrapes and applies a free **WARP+ Premium Key** from Telegram.
- Downloads optimized `geoip.dat` and `geosite.dat` from `hydraponique/roscomvpn`.
- Implements an anti-ECH (Encrypted Client Hello) routing fallback: all CIS IPs go `direct`, while ALL other foreign TCP/UDP traffic is forcefully routed through WARP+.
- Automatically enables `sniffing` in `routeOnly` mode for all inbounds.
- Mitigates HTTP/3 QUIC timeouts by blackholing UDP on port 443 for AI domains.
